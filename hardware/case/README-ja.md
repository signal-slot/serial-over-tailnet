# 3D プリント用ケース

VCC-GND Studio の YD-ESP32-S3（`YD-ESP32-23 2022-v1.3`）を収める、上が開いた一体型の箱である。
基板は USB-C 側を上にして上から差し込み、レセプタクルが縁と面一になる位置で止まる。

| ファイル | 基板 | 外形（幅 × 奥行 × 高さ） |
| --- | --- | --- |
| `yd-esp32-s3-case.stl` | ピンヘッダなし | 32.3 × 8.1 × 65.6 mm |
| `yd-esp32-s3-case-headers.stl` | ピンヘッダ付き、長いピンが裏面 | 32.3 × 17.0 × 65.6 mm |

どちらも立てた向きにしてあり、そのまま印刷できる。
サポートは要らない。

- `case.scad`: OpenSCAD のソースで、寸法はすべて先頭のパラメータにある。

基板の寸法はメーカーの図面（[vcc-gnd/YD-ESP32-S3](https://github.com/vcc-gnd/YD-ESP32-S3) の `ESP32-S3-Metric.pdf`）による。
平らな基板の裏を裏面の壁に当て、両端を溝で支える。
ピンヘッダ付き版は同じ箱を、ピンの 2 列の部分だけ広げたものである。
各列の裏にヘッダの樹脂とピンが入る溝があり、そのぶん裏を厚くしている。
外形は長方形のままである。
表側では、溝の押さえにピンの先端が通る切り欠きがある。
基板の裏に 8.5 mm 出る標準的なヘッダを前提にしている（`pin_below`）。

前面には、上端の `USB` と `COM` の刻印のほかは何もない。

## 印刷

PLA か PETG、積層 0.2 mm、壁 3 周で印刷する。
アンテナは箱の底側にあるので、そこには金属（金属入りフィラメントも）を近づけない。

## 調整

| パラメータ | 既定値 | 変える場面 |
| --- | --- | --- |
| `groove_clr` | 0.4 | 溝の厚みの PCB に対する余裕。実機では 0.15 だときつかった。 |
| `pin_below` | 8.5 | 基板の裏に出るヘッダの樹脂とピンの長さが違う（ヘッダ付き）。 |
| `clr` | 0.6 | 基板の左右の端と側壁のすき間。実機では 0.3 だと入らなかった。 |

```bash
openscad -o yd-esp32-s3-case.stl case.scad
openscad -D headers=true -o yd-esp32-s3-case-headers.stl case.scad
openscad -D 'part="assembly"' case.scad   # 基板を入れた状態のプレビュー
```
